# Experiments

```bash
python scripts/run_baseline.py
```

Результат: `results/tables/baseline_results.csv`.

## Window Sweep

Команда:

```bash
python scripts/run_window_sweep.py
```

Результат: `results/tables/window_sweep_results.csv`.

## Raw vs Filtered

Команда:

```bash
python scripts/run_filtered_vs_raw.py
```

Результат: `results/tables/filtered_vs_raw_results.csv`.

## Noise Experiment

Команда:

```bash
python scripts/run_noise_experiment.py
```

Результат: `results/tables/noise_experiment_results.csv`.
